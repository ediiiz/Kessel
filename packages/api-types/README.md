# `@kessel/api-types`

TypeScript types for the Kessel daemon's HTTP API, generated by [`ts-rs`](https://github.com/Aleph-Alpha/ts-rs)
from the Rust API structs. Nothing in `src/generated/` is hand-written.

## Regenerating

```sh
just types      # cargo run -p server --example export-types
```

Run it whenever you change an API type, including its doc comments: `ts-rs` copies them into the
generated files, and `apps/server/tests/types_are_in_sync.rs` compares the committed tree with a
fresh run byte for byte.

The generator also writes the barrel, `src/generated/index.ts`, with its exports sorted by file
name so the output is stable. `src/index.ts` is the only hand-written file.

## Consumers

`apps/web` imports the package once, in `apps/web/src/lib/api-types.ts`; components import from
`$lib/api-types`. The package ships TypeScript source (no build step); Vite compiles it with the SPA.

`src/generated/` is excluded from `oxfmt` only, because reformatting generator output would break
the sync test. `oxlint` and `tsc` still check it.
